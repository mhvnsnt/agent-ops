# attic/ — deprecated alternates

`ckpt` and `supervisor` (python) were an earlier parallel implementation of the
checkpoint tooling. They work, but they use a different checkpoint schema than
the canonical tools and are NOT referenced by any docs.

**Canonical tools (use these):**
- `checkpoint.sh` — see `CHECKPOINT_PROTOCOL.md`
- `supervisor.sh`

These attic copies are kept for reference only. Do not build on them.
Deprecated 2026-10-06 during the resilience consolidation.
