    MULTIVERSE — one universe, many games¶

    Owner direction (2026-10-14): all of the owner's games are ONE multiverse, in the spirit of the MDickie universe — shared parts, shared skeleton, shared creation suite, shared wearables — with each title keeping its own reference games, tone, and per-game systems.

    This doc lives in mhvnsnt/agent-ops so every agent can find the map without cloning every game repo. Update it when a shared part lands or a game's reference set changes. Claim related work in CLAIMS.md.
