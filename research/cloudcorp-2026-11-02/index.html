    Phase 1 — security audit verdicts (owner's hard gate)¶

    Method: full source audit per tool (package.json, Dockerfile, server.json, ALL of src/, scripts/ where present) — postinstall hooks, network egress, env/credential access, remote-code execution, obfuscation, write scope, telemetry. Environment forced the route: git clone is broken VM-wide and tarballs return 0 bytes through the proxy, so source was read via the GitHub contents API and raw file reads, cross-verified by blob SHA. Zero REJECTs. Universal findings: no preinstall/postinstall/prepare hooks anywhere, no telemetry/analytics anywhere, no ~/.ssh, ~/.aws, Keychain, or browser-profile access by any tool's own code.

    Honest limits¶

    • The tools are days old, single-author, 0-star. Greenlight is the only battle-tested piece. Everything is pinned to exact versions in tools/cloudcorp/mcp.json so an upstream change never reaches us silently; re-audit before any version bump.
    • npm is broken on the current VM (EPERM on registry writes), so test-runs that needed npm install were run where the environment allowed and are marked honestly in TEST-RUNS.md; anything not run is marked NOT-RUN with the reason, never claimed as working.
